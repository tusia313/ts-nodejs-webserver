About This Project

Created as part of my backend & TypeScript learning journey. It handles static file routing, custom 404 fallbacks, and asynchronous REST API fetching.

  • TypeScript 5.x with strict mode enabled
  • Node.js native HTTP & FS Promises API
  • Fast live-reloading powered by tsx
  • Typed JSON payloads from icanhazdadjoke API
